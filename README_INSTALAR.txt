BLOQUEADOR TIPO BRAVE PARA CHROME

Carpeta que debes cargar en Chrome:
C:\Users\ELY\Desktop\COSAS\chrome-brave-blocker\extension

Instalación:
1. Abre Chrome.
2. Entra en: chrome://extensions/
3. Activa "Modo de desarrollador" arriba a la derecha.
4. Pulsa "Cargar descomprimida".
5. Selecciona esta carpeta:
   C:\Users\ELY\Desktop\COSAS\chrome-brave-blocker\extension
6. Listo. No tiene interfaz. Trabaja en silencio.

Qué bloquea:
- EasyList
- EasyPrivacy
- uBlock filters
- uBlock badware
- uBlock privacy
- uBlock quick fixes

Contenido generado:
- 112,738 reglas de red para bloquear anuncios/rastreadores
- 13,726 reglas cosméticas para ocultar espacios de anuncios

Limitación real:
Chrome no permite copiar 100% Brave Shields porque Brave bloquea desde dentro del navegador con adblock-rust.
Esta extensión recrea lo máximo posible usando Manifest V3 + declarativeNetRequest.
