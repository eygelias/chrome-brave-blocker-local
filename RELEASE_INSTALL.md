# Instalar desde GitHub Release

## Opción recomendada: ZIP

1. Abre la página de Releases:
   https://github.com/eygelias/chrome-brave-blocker-local/releases
2. Descarga `chrome-brave-blocker-local-v2.1.0.zip`.
3. Extrae el ZIP en una carpeta fija, por ejemplo:
   `C:\Users\ELY\AppData\Local\chrome-brave-blocker-local-release`
4. Abre Chrome:
   `chrome://extensions/`
5. Activa **Modo de desarrollador**.
6. Pulsa **Cargar extensión sin empaquetar**.
7. Selecciona la carpeta extraída `extension`.

## Opción local dev

Usa esta carpeta local:

```txt
C:\Users\ELY\AppData\Local\chrome-brave-blocker-local\extension
```

## Nota

Chrome no instala extensiones `.crx` externas como una extensión normal de la Chrome Web Store. Para usarla desde GitHub, descarga el ZIP y cárgala descomprimida.
